차곡차곡은 어떤 앱인가요

차곡차곡은 개인이 자신의 자산·일정·할일·메모를 한곳에서 관리하려고 만든 개인용 웹앱이에요. 광고가 없고, 누구에게도 정보를 팔거나 넘기지 않아요.

저장하는 정보

  • 로그인 정보: 이메일 주소 (Firebase Authentication)
  • 직접 입력한 내용: 자산·대출·고정지출·기록·메모 (Google Firebase Firestore, 본인 계정에만)
  • 직접 입력한 할일: 본인 계정에만 저장 (시간을 넣은 할일은 30분 전 알림을 보내기 위해 씀)
  • 구글 캘린더에서 받아 온 내용: 일정 (화면에 보여주고 아침 브리핑·30분 전 알림을 만들기 위해)
  • 알림 기기 정보: 푸시 알림을 받을 기기의 알림 토큰

Firestore 보안 규칙으로 로그인한 본인만 자기 정보를 읽고 쓸 수 있어요.

구글 계정 정보를 쓰는 방법

사용자가 허용한 경우에만 다음 권한을 써요.

  • calendar.readonly, calendar.events: 캘린더 목록과 일정을 보여주고, 사용자가 앱에서 넣거나 고친 일정을 구글 캘린더에 반영

구글에서 받은 정보는 위 기능을 위해서만 쓰고, 다른 곳에 보내거나 광고·분석·인공지능 학습에 쓰지 않아요. 차곡차곡의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

자동 동기화

사용자가 ‘자동 동기화’를 켜면, 앱을 열지 않아도 일정·할일을 받아 오도록 GitHub Actions가 구글 연결 정보를 써요. 연결 정보는 본인 Firestore의 비공개 영역에만 저장되고, 공개 기록(로그)에는 내용 없이 개수만 남겨요.

보관과 삭제

  • 정보는 사용자가 지울 때까지 본인 계정에 보관해요. 앱에서 항목을 지우면 바로 삭제돼요.
  • 구글 연결은 앱 설정에서 끊을 수 있고, 구글 계정 → 서드파티 앱 액세스에서 언제든 해제할 수 있어요.
