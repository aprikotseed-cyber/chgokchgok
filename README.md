# 차곡차곡 · 나만의 자산 관리

PC·태블릿·휴대폰에서 같은 데이터를 보는 개인 자산 관리 웹앱이에요.

- **자산**: 저축·현금(예금/적금/연금/보증금…), 주식(국내 / 해외 / 연금저축, 매일 시세·환율 자동), 집(국토부 실거래가 → 시세 자동)
  - 종목마다 **매수·매도** 버튼: 증권사 앱과 같은 이동평균 방식 (매수하면 평균 매수가·원화 매입금액 재계산, 매도하면 평균은 그대로·원화 매입금액은 판 비율만큼 줄고 실현손익 기록), 거래 내역과 마지막 거래 취소
  - 주식 전체(국내·해외·연금저축 합산) 평가금액, 평가 손익과 수익률, 실현 손익
  - 주식은 보유금액순·이름순 정렬, 국내·해외·연금저축 중 먼저 보일 묶음을 핀으로 고정
  - 주택은 구매 가격을 넣으면 시세 대비 오른 금액과 수익률을 함께 보여줘요
  - 자산 탭 제목 옆에 저축·현금 + 주식 + 주택 합계와 산 가격 대비 수익률
  - 해외주식은 평균 매수가($)와 원화 매입금액(₩)을 함께 넣으면 매입 환율을 구해서, 원화 수익을 **주가 효과 + 환율 효과**로 나눠 보여줘요. 금액 칸은 $/₩ 전환 가능
- **부채**: 주택담보대출·신용대출·교직원공제회·기타, 원리금균등 / 거치 후 원리금균등(1·2·3년) / 원금균등 / 체증식 / 만기일시, 출금 계좌 표시
  - **상환스케줄 불러오기**: 은행·주택금융공사에서 받은 상환스케줄 엑셀(.xls, 내용이 HTML 표인 파일)이나 CSV를 불러오면 잔액·출금일(영업일)·회차별 원금과 이자·상환 기록이 스케줄대로 자동으로 맞춰져요. 파일 내용은 본인 Firestore에만 저장되고 저장소에는 올라가지 않아요
- **고정지출**: 항목별 매달 출금일·금액·분류·출금 계좌, 월 합계, 이번 달 남은 출금, 대출 상환을 포함한 이번 달 출금 일정, 분류별 합계
- **아침 브리핑 알림** (매일 오전 8시): 오늘 일정, 오늘 마감·지난 할일, 오늘이 상환일·출금일인 대출 상환과 고정지출. 앱 화면 알림 카드는 상환 5·3·1일 전, 출금 하루 전부터 (PC는 닫을 때까지 남음)
- **일정 넣기**: 일정 탭 빠른 입력('금요일 7시 헬스', '11/20 병원') 또는 비서에게 '넣어줘'. 시간이 없으면 종일, 요일만 쓰면 이번 주, 캘린더는 내용으로 자동 선택(운동 Exercise, 공연·영화·전시 Cherish, 생일 Birthday, 학교·업무·연수 Work, 대학원·그 밖 Life). 일정을 누르면 수정·삭제
- **비서**: 일정·할일('오늘 일정', '금요일에 뭐 있어', '이번 주 할일', '어머니 생신 언제야', '내일 3시 상담 넣어줘')과 자산·대출·고정지출 질문. 휴대폰 오른쪽 아래 버튼, 홈 맨 위 입력줄, PC는 / 또는 Ctrl+K, 마이크로 말해도 돼요
  - PC에서 앱을 열어 두면 그날 알림이 오른쪽 아래 카드로 떠서 닫을 때까지 남아 있어요
- 모든 금액은 반올림 없이 1원 단위까지 표시하고, 1원 단위로 입력해요
- **비서**: 휴대폰은 위쪽 말풍선 아이콘, PC는 왼쪽 메뉴의 '비서에게 물어보기'. 입력해 둔 내용만으로 답해요 (인터넷·AI 사용 안 함)
  - 질문에서 무엇을(상환·잔액·이자·고정지출·수익·환율…), 어떤 항목을(직접 등록한 이름, 줄여 말하거나 띄어쓰기·작은 오타가 달라도), 언제를(오늘·이번 주·다음 달·12월·작년…) 찾아서 답해요
  - 답이 엉뚱하면 말풍선 아래 '이 답이 맞지 않았나요?' → 원래 원한 것을 적어 두면 설정 → '비서 개선 목록'에 모여요 (모르는 질문은 저절로)
  - '목록 복사하기'로 금액을 가린 글을 복사해 Claude와의 대화에 붙여 넣으면, 알아듣게 고치고 시험 문제로 저장해요
- **저축 입출금**: 자산 탭 계좌마다 [입금] [출금] 버튼, '↑↓' 버튼으로 계좌 순서를 끌어서 바꾸기, 계좌 아래 입출금 내역 (기록 탭에도 함께 쌓임)
- **기록**: 월별 입금·출금·상환 내역 입력 (날짜는 오늘로 자동, 빠뜨린 예전 기록·추가 납입·중도 상환도 날짜를 바꿔 입력)
  - 기록하면 계좌 잔액·대출 잔액이 자동으로 바뀌고, 수정·삭제하면 되돌려져요 (예전 기록은 '잔액 반영'을 끄고 입력)
  - 연도별 합계, 선택한 해의 월별 표·항목별 합계·기록 목록
- **홈**: 저축액 / 주택 / 대출잔액과 총자산, 고정지출·상환 일정(앞으로 2주, 보기 전용), **자산 추이**(일별 최근 30일 · 월별 최근 12개월 · 연도별, 주식 포함 총자산). 앱을 열 때와 시세를 받아올 때마다 그날 총자산을 기록해요. 홈 맨 위에 어제 대비 변화(주식·저축·주택·대출별), 그래프를 누르면 전일·전월·전년 대비 변화

화면은 새로고침 없이 실시간으로 바뀌어요. 다른 기기에서 고친 내용, 매일 아침 들어오는 시세, 날짜가 바뀌면서 달라지는 D-day가 바로 반영되고, 새 버전이 올라오면 앱을 잠깐 내렸다 다시 열 때 자동으로 적용돼요.

`?demo`를 주소 뒤에 붙이면 예시 데이터로 둘러볼 수 있어요 (이 기기에만 저장).

## 처음 한 번만 하는 설정

### 1. Firebase (이미 만들어 둔 `chgokchgok` 프로젝트 사용)
1. [Firebase 콘솔](https://console.firebase.google.com) → chgokchgok → **Authentication → Sign-in method**에서 이메일/비밀번호 사용 설정
2. **Authentication → Users → 사용자 추가**로 본인 계정 1개만 추가 (회원가입 화면은 일부러 없어요)
3. **Firestore Database → 규칙** 탭에 `firestore.rules` 내용을 붙여넣고 게시
4. **Authentication → 설정 → 승인된 도메인**에 `aprikotseed-cyber.github.io`가 있는지 확인

### 2. GitHub Pages 배포
저장소 **Settings → Pages → Branch: main / (root)** 저장 → 몇 분 뒤 `https://aprikotseed-cyber.github.io/chgokchgok/` 접속

### 3. 시세 자동 수집 (실거래가·주가)
GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**에 두 개를 추가해요.

| 이름 | 값 |
|---|---|
| `DATA_GO_KR_KEY` | [공공데이터포털](https://www.data.go.kr)에서 **"국토교통부_아파트 매매 실거래가 자료"** 활용신청 → 마이페이지의 **일반 인증키(Decoding)** |
| `FIREBASE_SERVICE_ACCOUNT` | Firebase 콘솔 → 프로젝트 설정 → **서비스 계정 → 새 비공개 키 생성**으로 받은 JSON 파일 내용 전체 |

> 서비스 계정 키는 비밀번호와 같아요. **Secrets에만 넣고, 저장소에 파일로 올리지 마세요.**

그다음 **Actions → 시세 자동 업데이트 → Run workflow**로 한 번 실행해 보면 돼요. 이후 매일 오전 6시에 자동 실행돼요.
집 주소·종목 같은 개인 정보는 저장소가 아니라 Firestore에만 있어서, 저장소가 공개여도 드러나지 않아요.

## 집 시세 계산 방식
- 입력한 **시군구 코드 + 단지명(일부) + 전용면적(±2㎡)** 에 맞는 최근 24개월 거래를 모아요 (해제된 거래 제외)
- **최근 6개월 거래 중 최신 3건 평균**을 현재 시세로 써요. 6개월간 거래가 없으면 마지막 거래가를 써요
- 단지명이 안 맞으면 앱의 집 카드에 "이 지역에서 찾은 단지 이름" 후보가 떠요. 눌러서 바로 고칠 수 있어요
- 지분(공동명의 50% 등)을 넣으면 그만큼만 자산에 반영돼요

## 예측 가정
- 저축: 매달 적립액 + 연 이자율(월 복리)
- 주식: 지금 평가액 그대로 (매수·매도로 직접 관리, 주가 상승률은 가정하지 않음)
- 집: 현재 실거래가 시세 그대로 (집값 상승률은 가정하지 않음, 실제 시세는 매일 자동 반영)
- 대출: 상환 방식·만기·거치기간대로 매달 상환
- 대출 상환금이 저축에서 빠지는 것은 반영하지 않아요 (월 저축액에 이미 상환 후 남는 돈을 넣는 방식)

## 체증식 계산 방식
- 매달 원리금이 **같은 금액씩** 늘어나는 방식으로 계산해요.
- 대출에 **이번 달 원리금**(은행 앱·상환 스케줄표의 납입액)을 넣으면, 남은 원금·금리·만기로 "만기에 딱 0원이 되는 월 증가액"을 거꾸로 구해요.
- 원리금을 입력한 달을 기억해 두었다가, 다음 달부터는 그만큼 늘어난 금액으로 자동 계산해요.
- 이 방식은 한국주택금융공사 예시(3억·연 4.55%·30년, 첫 회 116만원, 140회차까지 원리금균등 153만원보다 낮음)와 일치해요. 다만 공사의 공식 계산식은 공개 자료에서 찾지 못했어요. 은행 상환 스케줄표와 차이가 크면 '이번 달 원리금'을 다시 넣어 주세요.

## 비서 알림 켜기 (처음 한 번)
1. Firebase 콘솔 → 프로젝트 설정(톱니바퀴) → **클라우드 메시징** 탭 → 맨 아래 **웹 푸시 인증서** → **키 쌍 생성**
2. 만들어진 키(B로 시작하는 긴 글자)를 복사해서, 앱의 **설정(오른쪽 위 톱니바퀴) → 비서 알림 → 처음 한 번: 웹 푸시 키 넣기**에 붙여 넣고 저장
3. 알림을 받을 기기마다 **이 기기에서 알림 받기**를 누르고 알림을 허용
   - 아이폰·아이패드는 Safari에서 **공유 → 홈 화면에 추가**로 설치한 앱에서만 켤 수 있어요 (iOS 16.4 이상)
4. GitHub 저장소 **Actions → 비서 알림 → Run workflow**로 바로 시험해 볼 수 있어요 (그날 보낼 알림이 있을 때만 와요)

- 알림은 GitHub Actions가 매일 **오전 8시**에 확인해서 보내요. 시세 수집과 같은 `FIREBASE_SERVICE_ACCOUNT` 시크릿을 써요.
- 대출은 **매달 상환일**을 넣어야 알림과 일정에 나와요.
- 주말·공휴일에 실제 출금일이 밀리는 것은 따로 계산하지 않아요.

## 구글 캘린더·할일 연결 (처음 한 번)

1. [구글 클라우드 콘솔](https://console.cloud.google.com/projectcreate)에서 새 프로젝트를 만들어요.
2. API 및 서비스 → 라이브러리에서 **Google Calendar API**, **Google Tasks API**를 사용 설정해요.
3. OAuth 동의 화면: 외부, 테스트 사용자에 본인 계정 추가, 마지막에 **앱 게시**.
4. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션, 승인된 자바스크립트 원본 `https://aprikotseed-cyber.github.io`.
5. 앱 설정 → 구글 캘린더·할일에 클라이언트 ID를 붙여 넣고 **구글 연결하기**.

받아 온 일정(어제~32일 뒤)과 할일은 Firestore `users/{uid}/data/agenda`에 저장돼 다음에 열면 바로 보여요. 구글 연결(접근 토큰)은 창을 연 동안 1시간 유지돼요.

## 앱 안 [업데이트] 버튼
자산 탭 주식 제목 옆 **업데이트**를 누르면 GitHub에서 Run workflow를 누른 것처럼 주가·환율을 바로 받아와요 (1분쯤 뒤 반영).
처음 한 번 앱 **설정 → 지금 업데이트 버튼**에 GitHub 토큰을 넣어야 해요.
1. [새 토큰 만들기 (Fine-grained)](https://github.com/settings/personal-access-tokens/new)
2. Repository access: Only select repositories → chgokchgok
3. Permissions → Repository permissions → **Actions: Read and write**
4. Generate token → github_pat_… 복사 → 앱 설정에 붙여 넣고 저장
